灵感库 · Windows 直播回放助手
版本 1.1 · 附三种 OBS 录制场景

这个助手负责把直播软件保存的本地录像上传到你的灵感库。
它不负责推流；请使用抖音官方直播伴侣，或在其他平台使用 OBS 等直播软件。

使用方法
1. 解压后双击 LinganLive.exe，无需安装 Python。
2. 在灵感库网站的直播页面创建你的设备，并生成配对码。
   将完整配对码粘贴到助手，点击“配对并保存”。
3. 打开抖音直播伴侣或 OBS，开启“本地录制”，设置录像保存目录。
4. 在助手中选择平台和同一个录像目录，点击“启动监测”，再开始直播。
5. 直播结束并结束本地录制后，文件稳定 60 秒且不再被录制软件占用，
   助手会上传回放。网站确认保存后，在“待处理”和“直播回放历史”查看。

三种录制画面
包内“OBS场景”提供：01 人物全屏、02 屏幕加左下角人物小窗、
03 竖屏上屏幕下人物。前两种为 1920×1080，第三种为 1080×1920。
按“OBS场景/使用说明.txt”在 OBS 分别导入并选中场景 JSON 与对应配置目录。
首次使用须手选你的摄像头、屏幕与音频设备，先录制 10 秒检查。
OBS 虚拟摄像头只传画面；抖音直播伴侣里的麦克风和电脑声音需分别设置。
人物区、屏幕区可在 OBS 调整；平台评论、礼物等由直播平台显示。

历史回放
“启动监测”之前已经存在的文件不会自动上传。
点击“手动上传历史文件”，选择 MP4、WebM 或 MKV 文件即可加入队列。
每个文件须大于 0 且不超过 8 GiB。文件数量不设固定上限。

运行与重试
监测仅扫描所选目录中的文件，请把直播录像直接保存在该目录。
同名 MKV 和 MP4 同时存在时优先上传 MP4，避免 OBS 重封装造成重复。
上传需要助手保持开启。关闭窗口会暂停上传；下次打开会恢复未完成队列。
“停止监测”只停止发现新录像，已经入队的录像会继续上传。
网络故障会自动重试；配对失效后停止重试，请在网站重新生成配对码。
首次处理大文件会计算完整 SHA256 校验，所需时间取决于硬盘速度。
已上传的相同内容会去重，原始录像始终保留在你的本地目录。

凭据与数据
配对码仅发送给 https://lingan-library.wozhe0196.chatgpt.site。
助手拒绝 HTTP 重定向，以避免把凭据发送给其他网站。
配对码通过 Windows DPAPI 加密保存在：
%LOCALAPPDATA%\LinganLive\pairing.dpapi
上传队列和目录设置保存在同目录的 state.json，里面不保存配对码。
助手不把凭据写入日志，不删除、不重命名、不修改原始录像。

说明
本工具尚未经过 Windows 代码签名，Windows 可能显示来源或运行提示。
请只从你的灵感库下载，并自行决定是否运行。
网站直播上传接口必须已经发布并配置存储，才能完成真实上传。
官方直播工具需自行安装并完成平台要求的账号授权与开播设置。
