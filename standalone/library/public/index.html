录制分段保存在此浏览器。上传失败可重试，也可下载到电脑；未完整结束的片段会单独标明。

使用 OBS 模板直播：导入、检查声音与开播
  1. 解压场景包。在 OBS 的“配置文件 → 导入”选择包内的配置目录，再从“场景集合 → 导入”选择 JSON 文件，并切换到这两个已导入的配置。
  2. 双击“摄像头”选择你的设备；屏幕场景中双击“电脑画面”选择要分享的屏幕。只分享单个窗口时，可将其替换为“窗口捕获”，按包内说明保持位置和大小。
  3. 检查音频混音器：讲话时麦克风有电平，播放视频时电脑声音有电平。戴耳机试听，先录制 10 秒确认人物、画面和声音。
  4. 在 OBS 启动虚拟摄像机，在抖音直播伴侣添加摄像头并选择 OBS Virtual Camera；麦克风和电脑声音需在直播伴侣中分别选择。平台提供推流地址时，可在 OBS 配置后直接开播。
  5. 在 OBS 开启本地录制，保存到直播助手监测的文件夹。录制结束后，回放会进入下方历史和“待处理”。

竖屏的人物区会裁切填满，横屏的人物小窗保持比例。评论、礼物和观众数字由直播平台显示，模板保存人物与分享画面。
