# 你的售卖网站

电脑售卖页：[打开店铺](http://localhost:8787/)

电脑管理页：[进入后台](http://localhost:8787/manage)

手机与这台电脑连接同一个 Wi-Fi 时：[手机管理入口](http://192.168.1.63:8787/manage)。此地址来自当前电脑网络配置，换网络后可能变化；电脑要保持运行，防火墙或 Wi-Fi 隔离可能影响连接。

登录密码在本目录 `.env.local` 文件的 `ADMIN_PASSWORD=` 后面。请自己保存，不要发给客户。

1. 进入“商品管理”，点“新增商品”。
2. 上传商品图片，填商品名、配套文字和价格。
3. 点“发布上架”，前台自动同步。
4. 购买说明、发货说明会自动跟随每件商品，不用修改。
5. 客户付款提交信息后，在“订单管理”查看联系方式；你私下沟通并处理。

QQ 已替换为 YOUR_QQ，两张微信/支付宝收款码已分别替换为你提供的图片。后台“店铺设置”仍可自行更换。

备用 QQ 为 YOUR_BACKUP_QQ。主 QQ 无法联系时，客户可以点击公告、客服窗口或商品详情中的备用 QQ。后台“店铺设置 → 备用联系方式”可以修改这个号码，不影响主 QQ 和收款码。

现在是本机可运行版本，尚未有公网正式网址。完成正式部署后会给你两个可从任意网络访问的地址：店铺地址和管理地址。已用隔离浏览器实测上传/上架、手机端下单和提交付款信息进入待核款；没有进行真实付款。完整桌面/手机与原站并排视觉比较、真实邮件投递仍未完成。
