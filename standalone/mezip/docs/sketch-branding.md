# 简笔画 game identity

The game wordmark and app icon outline the existing OFL-licensed Sketch Han font. Its license is retained at `apps/racing/fonts/Sketch-Han-OFL.txt`.

The three menu illustrations were edited with the built-in imagegen tool from the corresponding existing game menu covers. Files: `apps/racing/home-screen/sketch-time-trial.png`, `sketch-race.png`, and `sketch-sandbox.png`.

## Image prompt

Edit the attached racing game cover into a restrained Chinese simple-line-drawing (简笔画) videogame cover. Preserve its exact scene composition, camera angle, sports car silhouette, curved road, palm trees and city architecture. Draw every object with sparse slightly imperfect ink-blue (#28567d) pen outlines on warm pale ivory paper (#f5f0df). White/ivory flat car body, very light desaturated blue hatching only, almost no solid dark areas. Charming clean hand-drawn sketch, simple geometric forms, readable at thumbnail size. Subtle paper grain, restrained cream and blue only. No photorealistic surfaces, no neon, no glossy 3D rendering. Landscape 3:2 image. Replace any lettering, logos and brand marks with simple non-letter geometric strokes; no text anywhere. Full-bleed scene, no outer frame, no UI. This is a cover illustration for a browser racing game called 简笔画.

Per-cover direction: time trial keeps the rear-view car and uses a stopwatch sign; racing keeps two cars side by side and checkered flags; sandbox keeps the jump, attaches all four wheels normally, and removes the cube icon.

The mode registry supplies both the main preview and its thumbnail. Shared previews also use the time trial artwork. Track names, internal storage identifiers and original creator credits are preserved.
