手机拍照链接

只在同一可信 Wi‑Fi 内可用。

链接有效期会在生成后显示；手机首次打开后会建立本机配对。

使用方法

1

在电脑点击“生成手机拍照链接”，复制到手机浏览器或扫描后打开。

2

手机点“拍摄付款凭证”，可使用相机或相册，再发送到电脑。

3

回到本页检查金额、商家、时间、分类；点击“确认写入本机账本”。
