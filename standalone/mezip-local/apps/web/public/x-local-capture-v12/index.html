02 / ACTIVITY

行为记录

从已存在的 X 本地记录读取点赞、收藏、浏览与主动保存；在这里打开时只会定位到你原来保存的具体链接。

03 / FOLLOWING

关注的人

只显示你明确关注的博主。已加载的扩展可记录 X、抖音网页版和哔哩哔哩网页版的关注操作；其他平台可手动添加，不会登录、读取或伪造任何第三方账号数据。

03 / LINK COLLECTOR

任意链接收集

可以保存网页、文章、代码、帖子、视频、电影或应用链接。保存后会保留来源、作者、主要作用与标签；点击“打开原始内容”才会跳到对应页面。

↗

不跳转的功能，已经收进本页。 收集、标签、进度、再次收藏和查看原始链接都在这里完成；原始链接本身仍可按你的需要点击打开。

04 / WATCH HISTORY

电影与视频

记录真正想持续跟进的电影和视频。每一条可标记进度、已看完、打开原始内容，以及再次收藏到私人资料库。

观看进度 ≠ 实际观看时间

手动登记会明确显示为本地记录；连接到本机桥接时，也会读取已有的真实播放记录。不会把打开页面误算成看完。

05 / PRIVATE ARCHIVE

私人资料库

不是另一种自动捕获。只有你从已有的点赞、收藏、链接或观看记录中明确点击“加入私人资料库”，内容才会来到这里。

PRIVATE BY DEFAULT
★

删除原始记录不会自动删除这里的私人资料。电影、视频和网址内容会分别归纳，便于持续回看；你也可以保留重要内容、添加标签，并随时打开原始内容。

06 / TAG MAP

标签与兴趣

只按你自己保存的链接、观看记录与私人资料进行归纳；不调用外部推荐，也不生成不存在的内容。

TAGS

已使用标签

保存链接或加入资料库后，会按标题、链接来源和内容类型自动补充标签。点击标签即可打开有对应内容的板块。

COUNTS

记录构成

识别不准确时，在“私人资料库”中点“修改标签”，保存后将以你的标签为准。

07 / LOCAL CONTROL
