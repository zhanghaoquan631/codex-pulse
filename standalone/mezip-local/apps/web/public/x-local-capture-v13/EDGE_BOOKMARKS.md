# ME.zip Capture V13 · Edge 收藏夹

V13 是保留 V12 的独立入口，新增了一个本机收藏夹追查页：

`http://127.0.0.1:5174/x-local-capture-v13/index.html#bookmarks`

## 使用

### 自动同步（推荐）

1. 在 `edge://extensions` 载入或重新加载 `apps/browser-extension/mezip-capture`，并刷新已打开的网页。
2. 打开扩展弹窗，开启“自动同步 Edge 收藏夹”；如果 Edge 提示权限，请允许读取收藏夹。
3. 打开上面的 V13 链接，进入“Edge 收藏夹”。扩展会先发送一次完整快照，之后对新增、改名、移动和删除事件进行防抖同步。

### 离线兜底

如果扩展未运行，可在 Edge 打开 `edge://favorites`，点击右上角 `…`，选择“导出收藏夹”，再在 V13 选择 HTML 或 Chromium JSON 文件。导入只在当前页面解析。

页面会保留 Edge 节点的 `bookmarkId`，因此同一个网址出现在不同文件夹时不会被错误合并。V13 中的“隐藏”只影响本页显示，不会删除 Edge 收藏夹；要恢复显示，请点击“显示已隐藏”。

## 隐私与边界

- 文件只在当前浏览器页面内解析，记录写入当前站点的本机 `localStorage`。
- 页面只读取导出文件中的 HTTP/HTTPS 网址，不读取 Edge 密码、Cookie、登录状态或浏览历史。
- 普通网页不能直接读取实时收藏夹目录；实时读取由本地 ME.zip Capture 扩展完成。桥接服务没有时间戳快照时，页面会显示“尚未收到快照”，不会把空列表或连通性伪装成已同步。
- V12 原入口和原有数据保持不变。
