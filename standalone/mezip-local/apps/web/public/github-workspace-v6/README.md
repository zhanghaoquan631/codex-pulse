# ME.zip GitHub 工作台 V6

V6 是独立的修复入口，复用 V5 的视觉和真实 GitHub API，但不修改 V5、登录后空间或其他页面。

修复内容：

- 可选 API 失败提示使用稳定签名，不再触发 MutationObserver 循环。
- 仓库、代码片段和 Issues 筛选只绑定一次，不重复移动 DOM。
- 未授权或未连接时显示明确的连接状态；不伪造账号、仓库或同步成功。
- 直接打开 `#repositories`、`#issues`、`#tasks` 等深链接时仍会显示可操作状态。
- 同步授权仓库中的小型代码文件到只读代码片段库，保留仓库来源链接与收藏状态。
- 贡献热力图为每个格子标注真实日期，悬停或键盘聚焦可查看当天贡献次数。
