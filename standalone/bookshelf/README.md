# 我的书架 · 手机云端版

保留原书架的浏览、图集、主题和互动效果，提供管理员登录、分类管理、自动书目查询、电子版入口查询，以及手机封面和电子书上传。

本站使用 Sites 固定 HTTPS 地址。站点访问需要登录站点所有者的 ChatGPT 账号；书架后台另外使用原有管理员密码。上传文件和书架资料存储在服务器，电脑关机后手机仍可使用。后台路径为 `/admin`，直接收录路径为 `/admin?add=1`。

## 使用

后台收录或编辑一本书，输入书名或 ISBN 后选择“自动查书”。确认书目后选择“查找电子版”，检查作者、语言及入口类型，再添加到这本书并保存。系统区分完整下载、在线阅读、借阅、预览和购买，现代图书可能只有借阅或预览版本。

也可以直接上传自己持有的 PDF、EPUB 或 UTF-8 TXT 文件，单个最大 50 MB。封面支持 JPG、PNG、WebP、GIF，单个最大 10 MB。上传文件会验证实际格式。电子书附件和私人阅读笔记需要书架管理员登录；查询得到的外部入口可以显示在书籍详情中。

## 持久存储与备份

D1 保存书籍、分类、图集、设置、管理员密码哈希、会话和上传索引；R2 保存上传文件。首次部署通过秘密环境变量延续原管理员密码，并通过一次性受保护迁移导入现有收藏，个人资料不放进网页资源或源码。

后台 JSON 备份包含书目、电子版入口、私人笔记、分类、图集及设置，不包含文件字节、密码或会话。恢复前会验证字段与引用，全部验证成功后原子替换。云端与本地 Node 版本是独立的存储实例，后续使用手机云端版进行管理。

## 开发与验证

需要 Node.js 24 或更新版本。

```sh
npm install
node scripts/build.mjs
node scripts/cloud-smoke.mjs
```

`worker/index.mjs` 是 Workers 后端；`public/` 是实际部署的前端资源；`worker/lookup-core.mjs` 与 `worker/ebooks-core.mjs` 是无 Node 传输依赖的查询逻辑。`db/schema.ts` 和 `drizzle/` 提供只含结构的数据库迁移，运行请求不创建或改变表结构。

`scripts/sync-local.mjs` 是维护时从相邻本地项目同步前端及纯模块的一次性辅助脚本，独立运行此云项目不需要调用它。`scripts/build.mjs` 输出 `dist/client`、`dist/server/index.js` 及绑定和迁移描述。

测试使用临时 D1/R2 和测试密码，不修改正式账号或书架。Sites 发布由配套的托管流程保存精确源码版本并上传构建产物。不要把 `.env`、密码、服务凭证或个人数据库放入源码。
