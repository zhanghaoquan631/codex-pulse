## Solar lighting and scene controls (2026-09-26)

- Morning, daylight, dusk and starry-night presets share one continuous solar clock. A manual change takes 12 active seconds; automatic playback takes 24 minutes per illustrative day. This is a miniature-world time cycle, not an astronomical or live-weather feed.
- Sun position, light color, exposure, water, window emission and night lights interpolate together. Tree and building batches cast/receive shadows; the directional shadow camera follows the current map view across all twelve regions instead of staying at the world origin.
- High/balanced/light modes change actual pixel-density caps (2/1.5/1) and shadow sizes (4096/2048/1024). Mobile shadows are capped at 2048. All modes retain shadows; the browser remembers the selected quality. High quality costs more GPU time, and no frame-rate guarantee is implied.
- The existing locally stored Poly Haven sky photographs remain in use. Stars and moon are procedural, depth-tested behind the map, and fade in at night. The stars can be toggled independently.
- Scene tools add pause/resume, optional browser-synthesized environmental sound (off by default), PNG export and hide/restore interface. Manual time selection still works with traffic/residents paused. Background-tab time is excluded from solar and scene progress.
- Interaction ideas were inspected from https://s.baoyu.io/files/peach-blossom-land-v2/index.html. Its literary storyline and application source were not imported. The map's existing places, data, navigation and separate game entry are retained.
- Renderer integration is generated by `scripts/prepare-reference.mjs`; edit that adapter, not generated `app.js`. `solar-lighting.mjs`, `living-sky.mjs`, `night-sky.mjs` and `scene-tools.mjs` implement these features.
- `node scripts/audit-solar-lighting.mjs` tests the actual local WebGL page, captures desktop/mobile screenshots and compares rendered shadow/star pixels. Artifacts are saved under ignored `RECON/solar-lighting/`.

## Run

- `npm ci` installs pinned dependencies.
- `npm run dev` starts the local server on port 5242 only. Port 5241 belongs to an existing booking page and is untouched.
- `powershell -File .\Start-Atlas.ps1` starts a hidden server, or reuses this version if already running. It refuses to replace an unrelated service. This does not add Windows startup entries.
- `npm test` checks the data contract and adaptation regressions.
- `npm run build` generates `dist`.
- `npm run prepare:map` rebuilds the geographical snapshot from cached/public data.
- `npm run prepare:reference` regenerates the renderer/style adaptation from the captured reference. Make renderer edits in this script so regeneration retains them.

## Sources and scope

Reference: https://seoul-3d-atlas.synabreu.chatgpt.site/ (public v1.3 renderer and styles, adapted locally). Reference attribution is preserved in `public/REFERENCE-LICENSES.txt`. Do not assume its application code has the same license as Three.js. Public redistribution needs the relevant rights and license review.

Geography: OpenFreeMap / OpenStreetMap vector snapshot dated 2026-08-30; Mapzen / AWS Terrarium elevation tiles. The exact extent, URLs and representative points are recorded in `public/data/provenance.json`.

- Twelve regional navigation points, not twelve disjoint administrative areas.
- 108,661 elevation samples, 14,302 road segments and 1,450 water polygons.
- 230 OSM building footprints in sampled tiles around regional centers. These are simplified oriented blocks, not detailed architectural models. Coverage is sparse and is not a complete inventory.
- Trees, vehicles and boats follow the reference's illustrative rendering and animation, not measured vegetation or live traffic.
- Height is exaggerated 4x. Water beds are aligned below their water surfaces; the beveled foundation is below sea level.
- No Google Maps live rendering, satellite imagery stream, Google API key or private imagery extraction is involved.

The reference's orthographic scene, procedural trees, controls, day/sunset/night palette and camera transitions are retained. Seoul landmark models are deliberately excluded rather than mislabelled as Chaoshan buildings. This is a working geographic adaptation, not a claim of complete or pixel-identical regional reconstruction.
