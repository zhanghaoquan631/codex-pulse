# Editable map source

This is the separately maintained editable map snapshot imported on 2026-09-30. The exact deployed Codex Pulse map runtime remains under public/local-apps/chaoshan-atlas; do not automatically replace its reviewed runtime with this example.

Install with npm ci, then npm run dev or npm run build. Cached geographic preparation inputs are not bundled; the already prepared public/data snapshot is included.

The base atlas renderer/style was adapted from Seoul 3D Atlas; no blanket relicense is asserted. Keep REFERENCE-LICENSES.txt, photo credits and all source notices. See repository LICENSES.md.
