# 厦门 3D 旅游地图

独立厦门项目。预览 http://127.0.0.1:5243/ ，原潮汕项目与 5242 服务不变。服务器读取 dist；修改源码后运行 npm run build 即可刷新。电脑重启后用 Start-Map.cmd 启动。开发依赖已在本项目独立安装。

## 地图与生活场景

保留 Three.js 地形、路网、水面与 12 个地区主题场景；增加人物步行/交谈/休息、避让与活动范围、多种树木、车辆、城市建筑、岸线与分区环境。程序化地标和建筑属于示意，不是逐栋实测复原。

鼓浪屿不再使用孤立的三栋房屋示意区。新增岛级场景：432段地形贴合的步行街巷、33处程序化建筑、103栋沿街示意民居、40片地图地被、860株树木及165位动态人物。八卦楼、三一堂、天主堂、海天堂构、黄荣远堂采用不同轮廓；日光岩观景岩台与皓月园雕像另作表现。沙地不种树或建民居，人物落点及运动检查水面、建筑与他人。地标外形、体量和邻近摆放均为艺术示意，不是测绘复刻或真实入口。

`island-detail.mjs`负责岛级场景，`island-layout.mjs`记录覆盖范围和建筑轮廓参数。`node scripts/prepare-island-detail.mjs`从本地OSM道路快照及已缓存矢量瓦片生成`public/data/island-detail.json`，不在每次打开页面时请求外部地图。地被和路面贴合同一组地形三角面，避免坡面交错闪烁。人物采用分部位实例化绘制。

中山路、镇邦路和八市周边改为沿映射道路展开的老城街巷：274段街巷、55个路名、335栋示意骑楼/民居、6种立面组合、55株行道树与200位实例化行人。拱廊、阳台、女儿墙、侧后窗、遮阳棚与夜间窗灯分开处理。低路面贴合同一地形网格；原简化道路在详细范围内裁切，避免两套路面交叉叠层。人物在步行街或人行道活动，检测水面、建筑及其他行人；不模拟路口信号，也不把动画路径用作导航路线。

`oldtown-detail.mjs`负责老城场景，`oldtown-layout.mjs`负责覆盖范围、道路裁切及旋转建筑包围盒；`mapped-crowd.mjs`负责批量绘制行人。`node scripts/prepare-oldtown-detail.mjs`从同一09-13路网快照生成约65KB局部数据，不新增外部地图加载请求。中山路和镇邦路游览参考点已对齐该快照中的同名街道节点，不代表具体店铺或入口。

## 定位与时间轴

定位默认关闭，仅主动开启才请求设备权限。坐标只在本机处理，不提交外部路线服务。蓝线是实际记录轨迹，绿线是本地道路参考，橙色虚线只示意渡轮连接。移动方向与设备罗盘分别标注，不在低精度、过期、权限拒绝或范围外伪造位置。

路网来自2026-09-13 OpenFreeMap/OSM快照，局部步行数据覆盖鼓浪屿、中山路与东渡，包含9162节点、2069条道路。使用ngraph A*，断路不画直线补齐，异常绕行不显示。施工、台阶和入口需现场核对。定位覆盖范围 [117.98,24.38,118.25,24.62]，不是整个厦门行政区。

步行路线提供路名、左右转、分段距离、起终点和楼梯提示；分段按钮可放大该段。路线描边与楼梯着色保持近景清晰。已标注的码头/桥接段显示可见桥面，楼梯用踏步示意；并非逐级实测，不从4倍高程模型推断真实台阶数、坡度或上下行。桌面高画质启用至少1.5倍采样以减少锯齿。

岛内地被与步道路面合并重合顶点、平滑相邻法线，减少三角面明暗接缝，保持原有高程、道路坐标与寻路图不变；不以模糊贴图或隐藏楼梯来掩盖细节。近景仍是程序化微缩场景，不是摄影测量或逐块地砖还原。

“避开已标注楼梯”使用移除steps边的路网重新寻路，找不到连续路线时明确提示，不穿越空地补线；不等同于轮椅无障碍路线。GPS保持设备原始坐标，不吸附道路或移动到景点。精度超过35米、过期等情况下不显示路段判断。近岸水面定位不直接生成水面步行路线。分段提示是公开快照参考，不是商用逐向导航或实时封路服务。2026-09-28尝试取得原始OSM更新未成功，当前仍使用明确标注的09-13快照。

楼梯语义参考 https://wiki.openstreetmap.org/wiki/Tag:highway%3Dsteps ，浏览器定位精度参考 https://developer.mozilla.org/en-US/docs/Web/API/GeolocationCoordinates/accuracy 。未命名支路不借用邻近路名，所有未知数据均保留未知状态。

码头附近若底图将位置判作水面、但12米内有已映射步道，则先请求用户确认已经上岸，再允许规划；远离道路的水面不规划步行。确认不跨越30米位置变化或定位关闭。手机旋转后重新匹配路线焦点与剩余地图区域，避免镜头落在面板后方或海面空白。

时间轴记录开始、到达、离开、20分钟停留、定位中断和结束，以设备时钟显示北京时间到年月日时分秒。持续精确位置用于估算到访，不作到访证明。超过90秒的更新空缺和位置跳变不计入停留、不连接轨迹。关闭页面后不会继续计时。

默认记录只存在本页内存，用户可选择本机保存（最近5次旅行），查看轨迹、导出JSON及停止定位后删除全部记录。换浏览器、手机或域名不会自动同步。手机后台、锁屏可能暂停定位，网页不能保证全天后台连续记录。

手机需要 HTTPS 部署地址与定位授权。127.0.0.1仅限本电脑，不是公网或手机地址；此版本尚未公开部署。模拟定位测试不等于真实手机户外步行验收。
