# 浙大漫游 · Overworld

独立的校园探索游戏，复用紫金港的公开地图地理数据，以俯视跟随镜头和室内剖面呈现。

运行：在本目录执行 `python -m http.server 8766 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8766/ 。无需构建与地图密钥。

点击地面或小地图自动走，WASD / 方向键移动，R 切换跑步，E 开门或入座。底部工具栏可查找地点、选择课程/运动、换装；右上可在校园总览、俯视、第一人称之间切换。近景视角保留原校园的跑步、跳跃、游泳、交通、门窗、电梯、建造与课堂互动。

已接入原版十种动物与怪兽，模型外观保持不变。16 点学生与司机回房，18 点怪物出没，6 点消散。进入校园室内或完整自建房可避险；按 K 或点击近处怪物挥杖，生命归零后逐渐倒地并可从安全房间重开。校园生活面板可立即开始夜晚、关闭生存。昼夜一轮约 18 分钟。地图寻路和运动游戏继续可用；运动练习期间免受怪物伤害。此版本不加载毒圈与积分任务模块。原校园网站和源码保持独立。

建筑地理轮廓、道路、水体来自 OpenStreetMap（ODbL），详见游戏内「地图与还原说明」；建筑高度、立面、室内空间为近似或功能示意，并非浙江大学官方数字孪生。课程为模拟通识微课。

交互参考：[Overworld](https://www.motionin.design/gallery/overworld)。采用独立的 Three.js 实现，没有复制该付费模板源码。另参考本地 Tripo Astra 索引中固定等距视角、可控角色与点击移动的场景组织方式；没有调用 Tripo 云端模型或 API。

新模块：`overworld.js`（地图相机、室内剖面、点击移动、工具栏），`overworld.css`（桌面/触屏界面）。核心校园模块保留原有公共接口与 WebMCP 操作。
