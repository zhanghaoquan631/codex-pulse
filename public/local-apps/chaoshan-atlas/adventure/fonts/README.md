# 手写字体

这组字体根据用户提供的「LIFE FORCE」黑色手写字参考选择，追求笔画自然、字形略不齐的感觉；没有把截图中的字体当成已被精确识别的字体。

- **Sketch Latin**：Rock Salt Regular，Sideshow / Font Diner，来自 [Google Fonts 源仓库](https://github.com/google/fonts/tree/main/apache/rocksalt)。原始字体以 Apache 2.0 发布，许可全文在 `Rock-Salt-LICENSE.txt`。本地版本仅转换为 WOFF2，没有改动字形。
- **Sketch Han**：衍生于 [LXGW 悠哉字体 Yozai Medium v0.868](https://github.com/lxgw/yozai-font/releases/tag/v0.868)，原始版权属于 LXGW 与 Y.Oz，使用 SIL OFL 1.1，全文在 `Sketch-Han-OFL.txt`。本地版本转换为 WOFF2，保留全部原始字形；内部字体名称改为 Sketch Han，以遵守派生字体的保留名称要求。没有将字体单独出售。

转换日期：2026-09-12。两种字体均随关卡自托管，运行时不请求第三方字体服务。中文没有只截取当前四关的文字，未来增加故事与地点时仍能使用完整字库。标题、地名、门牌和任务采用手写风格；体力、经验与铜钱数字保留清晰的等宽数字排版。
