# Sources

Reference: https://isablyns.vercel.app/ (retrieved 2026-09-30)
Illustration, sprite sheet, clouds, bowl sprites and the Azeret Mono font are original deployed assets.
The cat state machine is copied from the inline mascot script in index.html.
The town live overlay is copied from js/footer.js.
The CSS is extracted from css/styles.css. The isolated theme adapter preserves night.js's
light → dark → e-ink → light cycle, themechange event and scene tokens.

Integration adaptations: independent upper/lower iframe rows; upper rail anchor;
theme bridge; keyboard activation for the cat; viewport clipping; the original
centered street crop on phones. Animation timing, sprite frames, wire physics,
bird roster, shop switches, steam, post-office letter and night effects are retained.
