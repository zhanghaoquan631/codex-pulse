# Codex Pulse

Codex Token / 缓存用量仪表盘，手机和电脑均可通过公开链接查看，无需登录。

## 已配置的功能

- “灵感库”（`#knowledge`）增加厦门 3D 地图预览卡片，封面取自公开地图的鼓浪屿实际渲染画面，点击进入 `https://xiamen-3d-map.wozhe0196.chatgpt.site/`。预览图片随本站发布，不依赖本机服务；原有灵感库入口保持不变。
- 同一“旅行地图”板块也包含潮汕 3D 地图卡片，使用公开地图实际渲染的全景预览，点击进入 `https://chaoshan-3d-map.wozhe0196.chatgpt.site/`。两张预览均完整显示，不裁切地图；手机和电脑沿用同一组入口。

- “预约系统”（`#booking`）接入 5224 底部的 Alex 15 分钟预约流程，日期与时分秒按 UTC+8 处理。新预约先保存 D1，15 分钟重叠时段拒绝重复占用；同 UUID 重试核对已有记录。管理账号可查看收到的预约，公开访问不会暴露联系人资料。邮件通过现有本机 relay 调用 5241 的原 163 SMTP 服务，需本机在线；发送结果不确定时保留操作回执，不重复发送。旧预约邮件仍在原邮箱中。

- “音乐空间”（`#music`）内嵌用户指定的 `https://music.zkkp.nyc.mn/`，提供全屏、重载与独立打开。在线音乐搜索、播放和下载由该站点处理，不在 Pulse 后端代理音乐或保存该站点 Cookie。访问依赖第三方站点可用性和 EdgeOne 验证；iframe 的 load 事件仅代表文档载入，不能证明应用可用。音乐页使用独立站点原界面，切离板块会卸载播放器、停止播放。源码项目：https://github.com/guohuiyuan/go-music-dl 。
- “潮汕 3D 地图”栏目已接入共创地图：全国社区地图、社区榜单、活动与政策、收藏和自定义地点。潮汕 3D 按需加载，新增地点可在地图定位。公开资料是 2026-09-26 快照；收藏和地点仅保存在当前浏览器。集成说明见 `integration/chaoshan-community/`。

- “ME·zip Pro”作为独立启动板块，提供原云站的登录、个人空间和作品游戏入口，并保留 `http://127.0.0.1:5202/#login`。所有入口在新页面打开以保留原站顶级登录流程，不代理身份或复制私人数据；本机版和云端版分别保存数据。
- “潮汕 3D 地图”提供地区探索、昼夜切换、自动巡游、平面视图、全屏浏览及十二章互动冒险。地图和游戏随网站发布，手机与其他电脑可直接访问，原 5242 页面保留。动物精灵按需从原公开 Petdex CDN 加载；游戏进度使用当前浏览器的 localStorage，原本机存档不会自动迁移。静态集成构建与来源说明见 `integration/chaoshan-atlas/`。
- 私人财务页默认显示全部历史账单和金额；本次页面可切换隐藏金额，原账本隐私设置保留。后台同步保留内嵌账本、详情和正在编辑的内容。
- “我的小店”连接现有云端店铺，提供商品商城、订单查询和店铺管理。商品、订单和图片沿用原店铺数据；管理仍使用原店铺密码，不依赖本机采集服务。
- 今日、7 天、30 天、今年和全部累计的真实用量。
- Token 总览默认显示全部历史，并记住时间和账号筛选；热力图按周一至周日对齐，可切换全部有使用记录的月份，空白日期不显示数字。浏览器缓存最后成功读取的快照，刷新或临时连接失败时保留上次结果；本机 SQLite 仍是完整历史的持久来源。
- 同步按每日总用量和调用数检查历史完整性，缺失或回退的历史返回 409 并保留原快照；并发更新重新校验，重复快照不会累加。账号归属调整在每日总量保持完整时允许更新。
- 自动读取本机登录邮箱，相同邮箱合并；按邮箱查看每日 Token、输入、输出、缓存和全部累计，所有账号总计包含无法归属的历史记录。
- 输入、输出、缓存命中、命中率、模型分布和最近 50 条记录。
- 每 10 秒读取本机新增日志并同步，网页每 5 秒刷新。
- 关闭网页不影响采集。电脑离线时保留最后同步结果。
- Windows 登录后自动启动采集器。
- 后台每 15 秒检查采集进程，异常退出后自动恢复；网络断开后本机继续记录，联网后补传。
- 跟随现有 Windows 网络代理设置变化重新连接。
- “网站”自动补录本机 Codex 正式回复中的网址，持续追加、去重并在云端保存。开发交付链接按上下文自动分类，其余放入“Codex 提供”。
- 收藏公开可见；使用网站创建账号登录后可以补充、编辑和删除。删除标记会保留，自动同步不会重新添加已删除的链接。
- “额度”每分钟读取当前 Codex 账号的 credits 余额，按 250 额度 = 10 美元保存余额变化，并用 Codex 登录邮箱分别显示。
- 相同邮箱的额度记录合并查看，显示各邮箱已确认消耗和待核实减少；余额取该邮箱最近一次读取，所有邮箱有限余额统一折合美元求和，未知或无限余额单独标示。
- 余额减少先列为“待核实”，确认是使用消耗后才计入已确认支出。接口没有逐笔扣费原因，无法自动区分邀请奖励、充值、过期或其他调整；离线期间只记录净变化。
- 可以手动补记 PHP、CNY、USD 等币种支出，按发生日期的可用参考汇率折合美元，保存原币金额、实际采用的汇率及日期。已保存的美元金额不会随后重算。

## 日常使用

双击“启动采集器.cmd”启动后台采集和自动恢复；双击“停止采集器.cmd”同时停止采集及守护进程，直到你手动启动或下次登录 Windows。
“关闭开机采集.cmd”和“开启开机采集.cmd”控制 Windows 登录后的自动启动。
请保留本文件夹。移动它之后需要重新运行“开启开机采集.cmd”更新启动位置。

## 数据说明

处理本机 `.codex/sessions` 和 `.codex/archived_sessions` 中的用量记录与助手正式回复中的网址。服务器只收到用量数字、网址、简短链接名称、时间、额度记录和账号邮箱，不包含对话全文、文件内容或 Codex 登录凭据。常见登录、授权、访问密钥、签名链接和嵌套凭据链接会被过滤；不会自动访问收藏网址。本机或内网网址只在相应电脑或网络可用。

缓存输入已包含在输入中，推理输出已包含在输出中。总量不额外相加这些子项。按 UTC+8 统计日期；重复累计不计数，子任务继承历史排除，累计回退和不一致记录使用单次用量校正。历史不完整时不推算缺失部分。旧版日志缺少模型或分项数据时保留“未知模型”或未分类数量。

这些数字代表可观察到的本机 Token 使用，不等于 ChatGPT 账户费用、额度，也不自动覆盖其他设备或未落地本机的云端任务。

在这台电脑切换 Codex 账号后，新日志继续记录。采集器每 2 秒在内存读取本机登录身份，只保存规范化邮箱及加盐哈希、连续观察区间。Token 请求开始和用量记录时间必须同时落在同一段连续账号区间才归属该邮箱；日志本身没有账号字段，因此这是按本机登录身份观察的归属。旧日志、停机或休眠空窗、账号切换边界和无法确认身份的记录保留为“账号未知”，仍计入所有账号总数，不会用当前邮箱追溯填充。重启后开始新的观察区间，使用记录和每天的合计持续保留。网站管理账号和采集账号是两件事。

网站已开启公开访问，任何获得链接的人都可以查看用量数字。数据写入仍需要本站专用同步凭据，公开访问不会开放写入权限。

## 本机数据与密钥

`collector/data/usage.sqlite` 保存去重后的本机用量和读取位置；日志文件保持原样。`collector/config.json` 是本机同步配置，包含本站专用同步凭据，不要分享。该文件及本机统计库均已排除在网站源代码提交之外。

`collector/data/websites.sqlite` 保存网址及独立补扫位置，`collector/data/credits.sqlite` 保存账号余额、显示邮箱、变动和本机随机盐。账号标识来自只读 Codex App Server 接口，在本机加盐哈希后才同步；按用户要求同步账号邮箱作为显示名称，不上传登录凭据。额度余额属于整个账号，可能包含其他设备的使用；它与仅来自本机日志的 Token 统计范围不同。

外币使用 Frankfurter 每日参考汇率；周末或休市时采用接口返回的可用日期。该数值可能不同于银行卡实际结算汇率。250 额度 = 10 USD 是用户指定的记账规则，折合金额不代表实际付现。

## 维护

需要 Node.js 24.5 或更新版本。网站基于 React / Vinext，云端用 D1 持久保存最新聚合快照。采集器不需要 npm 依赖。用量采集在电脑开机、Windows 登录且网络可用时同步；网络恢复后自动补录。

网站收藏以网站箱子展示。同一域名的路径和查询链接默认归为一箱（本机不同端口保持分开）；登录后可用“所属箱子”将换域名的同一项目合并，或把不同分支分别命名。按箱子分页，搜索命中子链接后仍能查看完整箱子。展开显示每条链接的首次、最近时间和按新到旧排列的交付记录，时间显示为台北年月日时分秒。交付记录由正式回复日志补录，重复扫描及 task_complete 回显不会重复添加；历史链接指向其当前内容，不代表旧版本页面快照。
